## Not built

_ These are not organized in any particular order; this may not be the best order to complete these tasks in._

Remaining suspect is render layering.
- **RAZOR's heads-down view shows no world.** It is the one herc whose view 1 declares a real 3D rect and a real `.HD1`; the engine's heads-down surface draws the art and the panels but never runs a 3D pass behind them. The rect and the spans are both read — see [`../formats/cockpit-views.md`](../formats/cockpit-views.md#vue--per-view-geometry) — so what is missing is a fourth panel camera, not data.
